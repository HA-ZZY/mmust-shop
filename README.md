MMUST Shop

MMUST Shop is a simple online shopping platform designed for students at Masinde Muliro University of Science and Technology (MMUST).

Features

User registration and login

View available products

Buy products

Sell products

User dashboard

Product management

Technologies Used

PHP

HTML

CSS

MySQL

Project Structure

index.php - Main page

login.php - User login

register.php - User registration

product.php - Product page

buy.php - Buying products

sell.php - Selling products

dashboard.php - User dashboard

logout.php - Logout

config/ - Database configuration

includes/ - Reusable PHP files

css/ - Stylesheets

Installation

Clone the repository.

Put the project inside your XAMPP htdocs folder.

Create the required MySQL database.

Update the database details in the config folder.

Start Apache and MySQL in XAMPP.

Open the project in your browser.

Purpose

This project was created as a simple student marketplace where MMUST students can buy and sell items.
